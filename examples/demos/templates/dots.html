LavaRnd dot plot

Each pair of random bytes is a point (x, y) on a 256 × 256 grid. Good random data fills the square evenly, with no pattern; the brighter a cell, the more often it has been hit.

A weak generator

About this demo

The weak generator is the linear congruential generator from the C standard's example rand() (x = x × 1103515245 + 12345 mod 2³²), taking the low byte of each output. Those low 8 bits repeat every 256 outputs, so the points it plots repeat too and only 128 of the 65,536 cells are ever hit, however long you watch. The standard's example avoids this by returning higher bits, but code that used the low bits of a generator like this got exactly this pattern. It runs in your browser and draws the same number of points as the LavaRnd plot.

Expected coverage is how much of the grid truly random points should have hit by now: 1 − e−n/65536 for n points.
