LavaRnd distribution

A histogram that fills in as random values arrive. The line is what perfectly random data would give; the bars settle onto it as the count grows.

About this demo

A single random byte is equally likely to be any value from 0 to 255, so its histogram is flat. Add two bytes and middle totals become more likely than extreme ones (there are more ways to make 255 than 0), so the shape is a triangle. Add eight and it's already close to a bell curve: the central limit theorem at work.

Values are grouped into 64 bins. χ² compares the bars with the line; p is the chance that truly random data would be at least this far off. It's shown once every bin expects at least 5 values.
