About this demo

If LavaRnd's output is uniform, every 4-bit value should appear about 1/16 of the time, every byte value about 1/256 of the time, and half of all bits should be 1. The magnified view zooms in on the expected value (the line) so you can see the small, random deviations from it. The shaded bands are ±1σ and ±2σ: about 68% and 95% of bars should land inside them. The unmagnified view starts the axis at zero, where the plots are almost completely flat because the data is so evenly distributed.

The movie plays the last {{ frames }} frames, oldest first. The large number in the corner is the frame number; frame 0 is the first full pool after the server started. χ² is the chi-squared statistic for the tally, and p is the chance that truly uniform data would give a value at least that large. p should be spread evenly between 0 and 1 from frame to frame, so a small p now and then is expected.

A rebuild of the randstatd demo from the original lavarand.org site (2003), which showed the same plots as animated GIFs.
